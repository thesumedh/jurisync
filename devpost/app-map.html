Architecture & Core Data Flow

Reference Code Tour (Key Locations)

Stop 1: Signal Extraction Heuristics
src/engine/signalExtractor.js → extractSignals()
Tokenizes input against curated dictionaries (AI, Biometrics, Employment, Health, Autonomous Actions) and produces a normalized boolean SignalVector.
Stop 2: Statutory Knowledge Base
src/engine/knowledgeBase.js → evaluateAllJurisdictions()
Evaluates the signal vector against statutory rules: EU AI Act (Annex III High Risk) & GDPR, India DPDP Act 2023 (Data Fiduciary obligations), and US NIST AI RMF / NYC LL144.
Stop 3: Cross-Jurisdictional Tension Engine
src/engine/tensionEngine.js → detectTensions()
Identifies direct friction points across international regimes (e.g. US retrospective bias retention vs India immediate data erasure vs EU ex-ante conformity).
Stop 4: Model Context Protocol (MCP) Server
mcp-server.js → handleRequest()
Provides a standalone JSON-RPC 2.0 stdio server implementing get_compliance_guidance, allowing external AI coding agents (Claude Desktop, Cursor, Antigravity) to call compliance orchestration directly.

A Practice to Reuse

Dual-Interface Orchestration (Human UI + Agent Protocol)

By implementing core business logic as a pure, deterministic engine (orchestrator.js), the same capability can be exposed simultaneously to human developers via an interactive web dashboard and to autonomous AI coding agents via the Model Context Protocol (mcp-server.js). This ensures seamless parity across developer-in-the-loop and fully automated agentic workflows.
